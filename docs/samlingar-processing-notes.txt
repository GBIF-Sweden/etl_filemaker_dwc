Mammals
=======
- Processing of dateIdentified is buggy or by design faulty. It uses catalogedDate instead. See JsonHelper:477
- Processing of eventDate is buggy. Adds date from previous record if current is invalid. See JsonHelper:606
- Years earlier than 1677 are not handled py pandas.to_datetime (se chatgpt)

= Source file
- Year, month, day may be invalid in source files
month: cat ZOO/verbatim/MAexport.csv | cut -d ';' -f 24 | sort -u
year: cat ZOO/verbatim/MAexport.csv | cut -d ';' -f 39 | sort -u
